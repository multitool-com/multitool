Combining several PDFs into one file should take seconds — not a subscription, not an upload to a strange server, and definitely not a watermark stamped across your contract. Here is the clean way to do it, plus what to check before you click.

## When you actually need to merge

- Joining scanned documents (contract + attachments + ID copy) into a single email-ready file
- Combining report chapters exported separately
- Attaching certificates to a résumé
- Merging receipts into one monthly expense file

If you instead need *part* of a file, remember the sibling tools: [PDF Split](/tools/pdf-tools/pdf-split) extracts pages, and [Remove Pages](/tools/pdf-tools/pdf-remove-pages) deletes what you do not want.

## The 30-second merge

1. Open the [PDF Merge](/tools/pdf-tools/pdf-merge) tool;
2. Add your files **in the final order** (the result follows the list order);
3. Click merge and download — the file is assembled **inside your browser** and never uploaded.

That last point matters more than people think: server-based mergers send your entire document to third-party infrastructure. For contracts, medical records or financial statements, browser-side processing is the only sensible default.

## What to check before merging (checklist)

- [ ] **Order** — drag files into the exact sequence you want before merging
- [ ] **Passwords** — encrypted PDFs must be [unlocked](/tools/pdf-tools/pdf-unlock) first
- [ ] **Page size** — mixing A4 with Letter keeps each page its own size (that is standard PDF behavior, not an error)
- [ ] **Rotated scans** — fix orientation per file first with PDF Rotate if some pages were scanned sideways
- [ ] **Size** — merging sums the parts; if the result must fit an email limit, [compress](/tools/pdf-tools/pdf-compress) the final file (not each part)

## Common problems and fixes

**"Nothing happens when I add the file."** The PDF is probably password-protected — the tool cannot read encrypted documents. Unlock it first.

**"The merged file is huge."** Expected: merge copies pages as-is. Compress the result afterwards — scans typically shrink 60–85%.

**"The order came out wrong."** Re-add the files in the correct sequence; reordering after the fact means splitting and merging again.

**"Forms stopped working."** If both PDFs contain forms with identical field names, they can conflict. Keep only the version you need before merging.

## Merging on phone

It works the same way: the tool runs in any modern mobile browser. On iOS, files from the Files app merge directly; on Android, pick documents from the picker. Big files (100+ MB) are slower on phones — give the tab a few seconds.

## The bottom line

Add files in order → merge → download. No account, no upload, no watermark — and the result is byte-faithful to the originals, which is exactly what legal and professional documents require.
